# 轻阅

Windows 本地 PDF 阅读器，重点是阅读、鼠标手绘和较低的渲染内存占用。

## 启动

解压 `轻阅-Windows便携版.zip` 后，打开 `QingYue` 文件夹，双击 `QingYue.exe` 即可使用，无需安装 Python 或其他运行环境。本机也可以双击 `启动轻阅.cmd`。可将 PDF 拖到启动文件或 EXE 图标上打开。
分发时复制整个 `dist/QingYue` 文件夹，不能只复制 EXE；放在当前用户可写的文件夹中。

## 使用

- **编辑原文**：阅读模式下双击 PDF 原文字，即可在原位置直接输入，没有弹窗或输入框边框；点击别处或 Enter 应用，Shift+Enter 换行，Esc 取消，Ctrl+S 保存 PDF。也可选择“编辑原文”后单击文字。选中文字所在的一段字体一致的文本进行替换，保留字号和颜色；字体采用支持中文的替代字体，必要时适度缩小以适应原区域，不能保证复杂排版完全一致。扫描图片上的文字、倾斜和竖排文字暂不支持。
- **编辑图片**：在“编辑原文”模式点击图片，选择替换或删除。替换沿用原图片的位置与显示范围，建议选择相同比例的图片；暂不处理内嵌图片、矢量图，以及被多处共用的图片。
- **保存 PDF 原文**：原文编辑先保存在会话临时副本中，窗口标题的 `*` 表示有未保存修改。Ctrl+S 或“保存 PDF”写回当前文件；“另存 PDF”保存副本。关闭或切换文件时提示处理未保存修改；原文操作支持 Ctrl+Z / Ctrl+Y。原文件已被其他程序改动时会要求另存，密码保护在保存时保留。
- **本机标注与原文保存**：保存 PDF 原文不会把本机笔迹合并进文件，笔迹仍自动保存在本机。要同时分享原文修改和笔迹，请使用“导出标注 PDF”。

- **形状标注**：在标注面板中选中矩形、圆形或椭圆，按住左键拖动可实时预览（圆形以按下位置为圆心，拖动距离为半径，最大范围限制在当前页内），松开保存并自动回到阅读模式；再次画形状需重新选择。支持颜色、粗细、显隐、撤销重做和导出；Alt 黑板擦可擦除部分轮廓。

- **快捷键帮助**：点击右上角 `?` 或按 `F1` 查看常用快捷键，再次点击或点击面板的 `×` 收起。

- **文字标注（左右键同时按下）**：在 PDF 页面上同时按住鼠标左右键，直接在页面当前位置实时输入文字，不弹出独立窗口；Enter 或点击其他位置保存，Shift+Enter 换行，Esc 取消。支持中文、多行、自动保存、显隐、撤销重做及导出为 PDF 文字标注。黑板擦或整笔擦除工具可删除整条文字标注。

- **精简阅读界面**：右侧竖排工具栏默认隐藏，只保留右上角“标注”按钮；鼠标悬停即可展开全部工具，鼠标回到页面后自动收起，不改变页面布局和阅读位置。
- **底部自动隐藏**：状态栏默认隐藏，鼠标移到窗口底边时浮现，移回页面自动收起；页面超出窗口宽度时，底部同时提供横向滚动条。浮层展开收起不改变阅读位置。
- **空格随手画**：鼠标放在 PDF 页面上，同时按住空格和鼠标左键拖动即可画线；松开任意一个立即结束并保存这一笔。单独按空格或移动鼠标不会画线。鼠标移出页面会断笔，切换窗口会结束绘制；在页码等输入框中不会触发。
- **打开 PDF**：展开“标注”中的打开按钮或 `Ctrl+O`；再次启动会自动打开最近阅读的文件。
- **拖入打开**：从资源管理器把 PDF 拖进阅读器窗口，松开即可打开；正在阅读时也能拖入另一份 PDF 切换，原文件的进度和笔迹会保存。支持中文、空格文件名；同时拖入多份 PDF 时打开第一份，非 PDF 文件忽略。
- **画笔（B）**：按住鼠标左键自由画线，松开即保存；支持颜色、粗细。
- **阅读（V / Esc）**：拖动页面，滚轮平滑连续滚动；相邻页面自然衔接。右侧滚动条对应整本文档，可直接拖到中间或末尾。
- **擦除整笔（E）**：点击或划过笔迹，删除本软件添加的一整笔。
- **黑板擦（Alt + 左键）**：同时按住 Alt 和鼠标左键拖动，只擦掉圆形范围经过的局部笔迹，保留同一笔其余部分。松开任意一个结束擦除；一次拖动可用 `Ctrl+Z` 完整撤销，`Ctrl+Y` 重做。仅擦除本软件在当前 PDF 上添加的本机笔迹。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`，保留当前打开文档会话中最近 100 个操作。
- **显示标注**：同时显示或隐藏 PDF 原有标注及本机新增笔迹，不会删除它们。
- **翻页**：上页、下页、页码输入框、`PgUp` / `PgDn`。
- **缩放**：适合宽度或百分比；也可按住 Ctrl 滚动鼠标。
- **恢复位置**：自动记录页码、页内滚动位置、缩放和标注显隐。
- **导出带标注 PDF**：保存为新 PDF，笔迹是标准 Ink 标注，能在其他 PDF 阅读器中查看、编辑。

## 保存方式

笔迹在每次松开鼠标或空格时写入本机 SQLite 数据库；阅读位置在操作后约 0.45 秒及关闭时保存。
数据位于程序旁的 `.reader-data/library.sqlite3`。备份时复制整个 `.reader-data` 文件夹。
原始 PDF 不会被修改；要分享笔迹，请使用“导出带标注 PDF”。即使隐藏了标注，导出仍包含全部标注。
移动/重命名 PDF，或修改其文件内容，可能作为新文档处理，原来的本机笔迹不会自动迁移。
输入的 PDF 密码不保存。受密码保护的 PDF 导出为**未加密副本**。

## 内存与当前边界

- 原生 Tk 界面，无浏览器或 Electron；采用连续页面布局，只渲染可见页面并预加载前后各一页。
- 单页栅格约限制在 300 万像素；可见页优先，预加载限制在总计约 800 万像素内。离开附近区域的图片会释放。
- PDF 渲染使用一个独立后台进程，最多一个任务在途，快速拖动滚动条不会堆积整本文档的渲染任务。
- 高倍率可能因像素上限不再放大；复杂 PDF 的解析内存仍取决于文件本身，不保证固定内存上限。
- 连续阅读版实测：233 页文字型示例 PDF，主进程与渲染进程工作集合计首屏约 160 MB，连续翻过 120 页后约 174 MB；这不是扫描件或所有 PDF 的内存上限。
- 已支持跨页连续阅读；尚无文字搜索、OCR、文本选择或目录侧栏。
- 擦除工具仅处理当前原始文件对应的本机新增笔迹；导出后再打开的笔迹属于原有 PDF 标注，只能显隐。
- 快速拖动到未加载页面可能短暂看到加载提示，滚动操作仍可继续；导出时界面可能短暂等待。无需网络账户，程序运行时不联网。

## 开发

Python 3.14 + Tkinter + PyMuPDF + Pillow。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe reader.py
```

打包需要 PyInstaller：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\build.cmd
```

构建脚本先生成 `build/release/QingYue`，再更新 `dist/QingYue` 中的程序文件，保留已有 `.reader-data` 阅读数据。

第三方组件保留各自授权条款；PyMuPDF / MuPDF 使用 AGPL 或商业授权，公开分发前应按所选授权处理源码与许可证。
